# まずこちらを読んでください — 猫つぶし 開発AI向け指示

## 依頼
このZIPが、Webゲーム「猫つぶし」実装の全資料です。`nekotsubushi_web_spec.md` を通読し、`references/` の6枚を必ず1枚ずつ**画像として開いて確認**してから実装してください。AIが画像を読まずに実装することは禁止です。

メニューから選べる6モードを、指1本・1プレイ10〜30秒程度のカジュアルなゲームとして実装し、猫の表情・毛並み・造形と原画像の画面構成を優先して仕上げてください。05「ほっぺむにむに」は時間制限なし。猫へのリアクションは漫画的な無害なちょっかいで、傷つける表現はありません。

## このZIPについて
元の31MBの資料から、AIには重複するPDF（19MB）を除き、**全文のMarkdown仕様書と配置データ、参照画像6枚**を残したものです。仕様書PDFとMarkdown本文は同じ内容なので、実装に必要な情報は省いていません。

画像は送信サイズ削減のためPNGからWebPに変換しました。画素寸法は941x1672です。`reference_manifest.json`に変換後のハッシュと元PNGのハッシュを記載しています。ファイルパスはWebP版に合わせて更新済みです。画像ビューアがWebPに対応しない場合は、あなたがローカルでPNGに変換してください。ユーザーに変換作業を頼まないでください。

## まず実行すること
1. `README.md`, `nekotsubushi_web_spec.md`, JSON/CSVすべてを読み込む。
2. `references/01_*.webp` から `references/06_*.webp` を1枚ずつ表示・観察し、どの猫の部位・背景・UIが動くかメモする。
3. 猫の顔パーツと毛並みを維持したアニメーション試作（01と05）を作り、実際にブラウザで撮影して画像に重ね、違いを直す。
4. メニューを作り、6モード全部を遊べるように実装する。
5. 各モードで照合用の状態を呼び出し、941x1672pxのスクリーンショットを撮って参考画像と比較・改善する。
6. iPhone Safari優先の操作検証・テストを完了し、連携権限がある場合はGitHubに保存しVercelへデプロイする。

### 出力の条件
- 原画像を画面全体に固定で貼るだけの偽ゲームは禁止。背景／前景／操作対象／猫アニメーション／UIを実際に分けて動かす。
- タップ・ドラッグ・長押しが実際にゲームとして動作し、メニューに戻り、再プレイできること。
- 品質不足なら素材制作・キャラクター造形からやり直し、必要な素材を自分で作る。
- 外部サービスのログインや料金発生など、AIに権限がないことだけ、ユーザーに具体的に確認する。
- 完成時に公開URL、最終画面6枚、元画像との比較画像、テスト結果、未解決点を提出する。
