# 継続・再挑戦・友人比較の改善版

対象はルール版2。最終アプリのエントリーは `/assets/index-cdHTuW4C.js`、CSSは `/assets/index-Bhu8JXUe.css`。既存の公開先とリポジトリを継続使用し、ログイン・課金・DB・ランキングサーバーは追加していない。

## 実装範囲

- 全6モードに連続成功、タイミング評価、寸止め残りms、近距離時間、頬の6ジェスチャーを追加。順位と表示は共通の成績モデルを使用。
- 結果に具体的な自己ベストとの差、直前の記録、友人との比較を表示。再挑戦はCanvas・テクスチャを再利用し、共有画像の生成は共有画面を開いたときだけ行う。
- 日本時間で更新する日替わり5モードと、seed・ルール版・目標記録を共有する挑戦状・返信リンクを実装。PNG保存、コピー、ネイティブ共有と代替操作に対応。
- 同じ猫の高品質ポートレート12枚を新規制作。ゲーム中の局所的な目・耳の反応、発見通知、表情コレクション、本編Sceneによる仕草の再生を追加。
- 保存v2へ非破壊移行。v1のキーは変更せず、旧寸止め長押し秒数を新しい残りmsと分けて保持。通常ベスト、直前成績、直近90コース、発見した表情を端末内に保存。
- 表示幅とDPRに合わせて描画バッファーを調整し、画面サイズ変更にも追従。941pxの参考画像キャプチャは元解像度を維持。
- GitHub Actionsに単体テスト、ビルド、Chromium／WebKitのブラウザ検証を追加。Actionsの依存は検証済みコミットSHAへ固定。

詳細な判定・順位・日付・URL仕様は [改善仕様](../docs/replay-improvements.md) を参照。

Chromiumは全体実行に、修正した幅の検証と不正seedの追加検査を組み合わせた集約。WebKitも全体実行と、表情プレビューを開いたままの再読み込みを再検査した集約である。両方とも同じ最終エントリーを検査し、元の実行結果・再検査結果・項目別出典を各レポートに残した。単一実行で12項目すべて成功したという扱いにはしていない。

WebKitの再検査では、プレビューを開いたままDOMの読み込みとアプリの準備完了を待ち、6種類の表情の保存・復元を確認。その後のプレビュー再生と明示的な破棄も確認した。初回のページ全体のload待機タイムアウトは元レポートに保持している。

両ブラウザで20回の実時間プレイ・再挑戦を行い、同一Canvasと主要素材の再取得ゼロを確認。レポートの再挑戦所要時間にはPlaywrightの待機・通信時間を含むため、実機の入力遅延の測定値とは扱わない。

描画検証は最終ビルドの12項目に、先行して確認した6ジェスチャーの静止画と1件の再挑戦を出典付きで参照している。最終ビルドでは通常時計で6ジェスチャーを再度操作し、38.28秒の動画へ記録した。6モードの基準表示は旧公開版の基準画像と画素差ゼロ。原画像へのSSIMは順に0.60785／0.75586／0.60188／0.71072／0.81163／0.65419で、構図・色の差を記述する値として保存し、合格点とは扱わない。

## 未検証事項と仕様上の境界

- 物理iPhone／Android端末は未接続。iOS Safari実機の発熱、長時間FPS、ブラウザバー、OS中断・音の復帰、最低性能端末・指定回線条件の数値は未検証。
- OSの共有シートそのものはヘッドレス環境では開けない。API分岐、キャンセル、画像保存、リンクコピーと送信失敗時の代替操作は自動検証し、実機OS・送信先アプリごとの見え方は未検証。
- 挑戦状は端末からの自己申告記録。サーバー照合、不正防止済みの順位、友人の記録の自動更新は提供しない。返信リンクで新記録を共有する。
- 猫は元画像を基に再構成した2D素材・メッシュ・パーツによる表現。原画像との完全な画素一致や全アンカー0.5%以内を保証する検査ではない。新規12枚は表情ポートレートで、動きは既存の被毛を保つ局所アニメーションを組み合わせる。

公開したコミットとVercelの検証情報は [deployment.json](../deployment.json) を参照。初版の検証履歴は [report.md](report.md) に保持している。
